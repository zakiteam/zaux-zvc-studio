## Runtime CSS overriding static responsive classes — 2026-10-07

Cause: `/api/preview-css` re-emitted every class found in the document JSON (including words like `hidden`/`block` in text or prop values) into the iframe <style>, after the static CSS, so base utilities beat the static responsive variants used by templates.
